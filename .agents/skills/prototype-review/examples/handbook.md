## 1 简介

### 1.1 关于本手册

本手册旨在帮助您快速理解并熟练使用 GenericBiz。本文档按照"由浅入深"的顺序，依次介绍产品定位、快速上手、功能详解与常见问题。手册配套在线帮助中心，建议结合使用。

### 1.2 适用读者

- **系统管理员**：负责系统初始化、用户与权限管理。
- **业务主管**：负责团队任务分发、流程审批、数据分析。
- **普通员工**：处理日常任务、提交数据。
- **外部协作者**：参与指定流程（如供应商、客户）。

### 1.3 术语说明

| 术语 | 含义 |
|------|------|
| 任务 | 需要某人或某团队在限定时间内完成的事项 |
| 流程 | 由多个审批节点组成的有序业务过程 |
| 表单 | 用于采集与展示业务数据的可视化容器 |
| 仪表盘 | 多维指标的集中可视化页面 |
| SLA | Service Level Agreement，服务等级协议 |
| RBAC | Role-Based Access Control，基于角色的访问控制 |

### 1.4 阅读约定

| 标识 | 含义 |
|------|------|
| 💡 提示 | 实用小技巧 |
| ⚠️ 注意 | 可能导致误操作的内容 |
| 🚫 警告 | 不可逆或高风险操作 |
| ⌨️ 快捷键 | 键盘快捷方式 |

> 💡 **提示**：本手册以 PC 端 Web 界面为例，移动端界面布局与操作逻辑基本一致。

## 2 产品概述

### 2.1 产品定位

GenericBiz 是一套帮助组织"把事情做对、把事情做完"的通用业务管理系统。它覆盖**任务协作、流程审批、数据采集、统计可视化**等高频场景，可作为团队的"业务操作系统"。

### 2.2 主要功能一览

| 功能模块 | 一句话描述 |
|----------|------------|
| 组织与权限 | 灵活定义人员、角色、菜单与数据权限 |
| 任务中心 | 任务从创建到归档的全生命周期管理 |
| 流程审批 | 通过拖拽方式配置审批流，支持加签、转签、驳回 |
| 数据表单 | 通过可视化设计器快速搭建业务表单 |
| 统计报表 | 仪表盘、图表、订阅推送，洞察业务全貌 |
| 消息中心 | 站内、邮件、企业 IM 多通道触达 |
| 开放 API | 通过 OAuth2.0 与企业现有系统打通 |

### 2.3 系统架构简介

```
+--------------------------------+
|       用户层                   |  ← Web 浏览器 / 移动端
+--------------------------------+
              |
+--------------------------------+
|       网关层                   |  ← Nginx + 鉴权 + 限流
+--------------------------------+
              |
+--------------------------------+
|       应用层                   |  ← 业务服务（前后端分离）
+--------------------------------+
              |
+--------------------------------+
|    数据与中间件层              |  ← MySQL / Redis / ES / OSS
+--------------------------------+
```

## 3 快速上手

### 3.1 系统要求

- **操作系统**：Windows 10+、macOS 11+、Linux 主流发行版。
- **浏览器**：Chrome 100+、Edge 100+、Firefox 100+。
- **网络**：稳定的互联网或内网连接。

### 3.2 访问入口

1. 在浏览器地址栏输入系统 URL，例如：`https://biz.example.com`。
2. 首次访问可能需要信任企业 SSL 证书。

### 3.3 登录

1. 输入账号与密码。
2. 点击「登录」。
3. 首次登录强制修改初始密码（密码至少 8 位，包含大小写字母与数字）。

> ⚠️ **注意**：连续 5 次密码错误，账号将被锁定 30 分钟。

### 3.4 首次使用引导

登录后系统会弹出新手引导窗口，包含 4 个步骤：

1. 完善个人资料
2. 查看我的任务
3. 学习如何创建任务
4. 探索仪表盘

引导可随时跳过，已完成步骤将不再出现。

### 3.5 主界面布局

```
+---------------------------------------------+
| Logo  |  顶部菜单（消息/帮助/个人中心）       |
+------+--------------------------------------+
|      |                                      |
| 左侧 |           主工作区（列表/表单/详情）   |
| 导航 |                                      |
| 栏   |                                      |
|      |                                      |
+------+--------------------------------------+
```

- **左侧导航栏**：可收起/展开，菜单根据权限动态显示。
- **顶部菜单**：消息中心、帮助中心、个人设置、退出登录。
- **主工作区**：内容呈现区域，支持标签页切换。

## 4 功能模块说明

### 4.1 个人中心

#### 4.1.1 修改个人资料

1. 鼠标悬停右上角头像 → 点击「个人中心」。
2. 修改头像、姓名、邮箱、手机号等信息。
3. 点击「保存」。

#### 4.1.2 修改密码

1. 「个人中心」→ 「安全设置」。
2. 输入旧密码与新密码。
3. 点击「保存」并重新登录。

#### 4.1.3 通知设置

按事件类型（任务指派、@提及、审批结果、订阅推送）勾选通知通道。

### 4.2 任务中心

#### 4.2.1 创建任务

1. 进入「任务中心」→ 点击「新建任务」。
2. 填写：

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 标题 | 必填 | ≤ 50 字 |
| 描述 | 选填 | 支持富文本 |
| 负责人 | 必填 | 单选 |
| 协作人 | 选填 | 多选 |
| 优先级 | 必填 | 低/中/高/紧急 |
| 截止时间 | 选填 | 需晚于当前时间 |
| 附件 | 选填 | 单文件 ≤ 50MB，最多 10 个 |

3. 点击「保存」。

#### 4.2.2 处理任务

- **待处理**：在「我的待办」中查看，点击进入详情 → 「开始处理」。
- **进行中**：在「我负责的」中查看，可更新进度或上传结果。
- **已完成**：在「我完成的」中查看，可发起复盘或归档。

#### 4.2.3 任务筛选

- 支持按状态、负责人、优先级、时间范围筛选。
- 支持关键字全文搜索（标题、描述、附件名）。
- 支持保存为"我的视图"以便复用。

### 4.3 流程审批

#### 4.3.1 发起审批

1. 进入「流程中心」→ 选择「请假申请」。
2. 填写表单（如请假类型、起止时间、原因）。
3. 点击「提交」，流程进入审批环节。

#### 4.3.2 审批操作

| 操作 | 说明 |
|------|------|
| 同意 | 流转到下一节点 |
| 拒绝 | 流程结束，申请人收到通知 |
| 加签 | 临时增加审批人 |
| 转签 | 将任务转交给其他审批人 |
| 退回 | 驳回到上一节点或指定节点 |

#### 4.3.3 查看审批记录

在「我发起的」或「我的待办」中点击单据编号，查看完整审批链路、时间、意见。

### 4.4 数据表单

#### 4.4.1 设计表单（仅管理员）

1. 「系统管理」→ 「表单设计」→ 「新建表单」。
2. 从左侧拖拽字段（文本、数字、日期、附件、子表单等）至画布。
3. 配置字段属性、校验规则与默认值。
4. 点击「保存」与「发布」。

#### 4.4.2 填写表单（普通用户）

1. 进入「数据录入」→ 选择对应表单。
2. 填写并提交。
3. 提交后可在「我的数据」中查看与跟踪。

### 4.5 统计与可视化

#### 4.5.1 仪表盘

- 提供 4 个默认仪表盘：总览、个人、团队、部门。
- 支持自定义：拖拽卡片、添加图表、调整布局。

#### 4.5.2 报表

- 类型：柱状图、折线图、饼图、表格、漏斗。
- 支持按时间、部门、人员等维度钻取。
- 支持导出 PNG / PDF / Excel。

#### 4.5.3 订阅推送

1. 在报表右上角点击「订阅」。
2. 选择周期（日/周/月）与接收人。
3. 报表将按设定时间自动发送至邮箱或企业 IM。

### 4.6 消息中心

| 通道 | 适用场景 |
|------|----------|
| 站内消息 | 必选，最基础的通知方式 |
| 邮件 | 重要事件、订阅报表 |
| 企业 IM（钉钉/企微） | 即时提醒，移动优先 |

> 用户可在「个人中心 → 通知设置」中按事件类型灵活配置。

### 4.7 系统管理（仅管理员）

- **组织架构**：拖拽调整部门层级，支持虚拟组织。
- **角色管理**：基于角色分配菜单与数据权限。
- **字典维护**：维护业务中下拉、单选等选项。
- **操作日志**：查看关键操作的审计记录。
- **参数配置**：调整系统级参数（如是否开启注册、默认密码策略）。
- **备份恢复**：支持全量与增量备份，一键恢复。

### 4.8 快捷键一览（节选）

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + K` | 快速搜索 |
| `Ctrl + N` | 新建任务 |
| `Ctrl + S` | 保存当前表单 |
| `Ctrl + /` | 显示/隐藏左侧导航 |
| `Esc` | 关闭弹窗 |

## 5 常见问题（FAQ）

**Q1：忘记密码怎么办？**
A：在登录页点击「忘记密码」→ 通过手机号或邮箱验证码重置。如无法自助重置，请联系系统管理员。

**Q2：账号被锁定怎么办？**
A：等待 30 分钟后自动解锁，或联系管理员手动解锁。

**Q3：上传附件失败？**
A：单文件最大 50MB；如仍失败，请检查网络或联系管理员确认存储服务状态。

**Q4：审批人离职了流程怎么办？**
A：管理员可在「流程管理」中将该节点的审批人切换为"角色 + 备用审批人"。

**Q5：能否导出数据？**
A：列表页右上角点击「导出」即可下载 Excel；大数据量请使用「订阅推送」。

**Q6：能否在手机端使用？**
A：可以通过浏览器访问 H5 移动版；如有需要可联系厂商对接原生 App。

**Q7：误删的数据可以恢复吗？**
A：在「回收站」中可恢复 30 天内删除的数据。

## 6 故障排除

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 页面 404 | URL 错误或服务未启动 | 检查地址；联系管理员 |
| 登录后空白 | 浏览器缓存异常 | `Ctrl+Shift+R` 强制刷新；或清缓存后重试 |
| 提交失败 | 网络抖动 | 稍后重试；若仍失败查看「消息中心」错误提示 |
| 数据不一致 | 多端同步延迟 | 等待 30 秒后刷新页面 |
| 报表加载慢 | 数据量过大 | 缩小时间范围或筛选条件 |
| 通知收不到 | 通知设置未开启 | 检查「个人中心 → 通知设置」 |
| 按钮无响应 | 权限不足 | 联系管理员确认权限 |
