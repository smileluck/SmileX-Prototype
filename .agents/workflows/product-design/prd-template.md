## 7. 交互状态与空状态设计标准

> 本章为全平台强制内容，所有产品都必须包含。详细规范参见工作流阶段 3.1 / 3.3 与 prototype-review 技能。

### 7.1 组件交互态要求

| 组件 | 必须状态 |
| :--- | :--- |
| [按钮] | [默认/悬停/点击/禁用/加载中] |
| [输入框] | [默认/聚焦/输入中/校验错误/禁用] |
| [表格行] | [默认/悬停/选中/展开] |
| [筛选项] | [未选/选中/悬停] |
| [标签页] | [激活/非激活/悬停] |

### 7.2 操作反馈要求

| 反馈类型 | 触发场景 | 设计要求 |
| :--- | :--- | :--- |
| [模态确认] | [删除/提交等不可逆操作] | [二次确认弹窗，含取消按钮] |
| [Toast] | [保存成功/操作失败] | [顶部/底部浮层，3秒自动消失] |
| [loading] | [数据请求/提交] | [按钮内 loading 或遮罩] |
| [校验] | [表单提交前] | [字段下方红色提示，禁用提交按钮] |

### 7.3 空状态要求

| 空状态场景 | 设计要求 |
| :--- | :--- |
| [空列表] | [插画 + 引导文案 + 新建按钮] |
| [无搜索结果] | [提示文案 + 清空筛选按钮] |
| [加载中] | [骨架屏或加载动画] |

### 7.4 异常状态要求

| 异常场景 | 设计要求 |
| :--- | :--- |
| [单条失败] | [行内红色提示 + 重试按钮] |
| [设备离线] | [状态标签置灰 + 离线图标] |
| [批量异常] | [告警条提示异常数量] |
| [网络断开] | [全局断网提示条] |
